# Identidad de Orquesta

- `orquesta-banner.svg`: portada del repositorio; incluye un ejemplo de equipo, no una captura del panel.
- `orquesta-mark.svg`: símbolo de la marca en formato vectorial.

Ambos SVG son editables, no cargan recursos externos y mantienen un fondo propio para verse en los temas claro y oscuro de GitHub.

| Uso | Color |
| --- | --- |
| Fondo | `#101216` |
| Director | `#A7BEFF` |
| Implementadores | `#EFBD7B` |
| Decisiones resueltas | `#88D2B1` |
| Texto | `#F4F6FA` |

Los nombres Codex, Claude Code, Astra y Opus identifican los clientes y modelos compatibles; el símbolo de Orquesta es propio del proyecto.
